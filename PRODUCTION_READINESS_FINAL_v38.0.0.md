## Architecture & Design

### 4-Ring Architecture (ENFORCED)
```
Ring 4: UI/OS (React + Tauri)
├─ Components/Pages
├─ Event handlers
└─ Browser/OS integration

Ring 3: Services (I/O Layer)
├─ API clients
├─ Database services
└─ File system

Ring 2: Engines (Business Logic - 9 Moteurs)
├─ Message engine
├─ Chat engine
├─ Memory engine
├─ AI engine
├─ Performance engine
├─ Sync engine
├─ Security engine
├─ Offline engine
└─ Telemetry engine

Ring 1: Core (Types)
├─ Interfaces
├─ Constants
└─ Shared types

RULE: Inner rings NEVER import outer rings ✅
```

### Design Patterns Applied
```
✅ Kernel Pattern - Ring 1 isolation
✅ Factory Pattern - Object creation
✅ Adapter Pattern - Service abstraction
✅ Observer Pattern - Event handling
✅ Strategy Pattern - Algorithm selection
✅ Facade Pattern - Complex subsystem simplification
```
